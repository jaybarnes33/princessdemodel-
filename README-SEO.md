## 🚀 Quick Deploy

### For Apache Hosting
```bash
# 1. Backup current site
cp -r /path/to/site /path/to/backup

# 2. Upload these files to root directory:
- index.html
- robots.txt
- sitemap.xml
- .htaccess

# 3. Set permissions
chmod 644 index.html robots.txt sitemap.xml .htaccess

# 4. Verify
curl https://princessdemodel.com/robots.txt
curl https://princessdemodel.com/sitemap.xml
```

### For Other Hosting (Netlify, Vercel, etc.)
```bash
# Upload:
- index.html
- robots.txt
- sitemap.xml

# Note: .htaccess won't work (Apache only)
# Use platform-specific redirect/header config instead
```

### Common Issues
- **.htaccess causing errors?** → Check Apache modules or remove temporarily
- **Sitemap not working?** → Verify XML syntax and absolute URLs
- **Meta tags not showing?** → Clear cache, wait 24 hours
- **HTTPS issues?** → Check SSL certificate installation
